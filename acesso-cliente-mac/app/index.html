🗄️ Backup dos Dados

Exporte seus dados para um arquivo de backup. Use para transferir para outro dispositivo ou navegador.

👥 Importar Moradores (CSV)

Importe moradores de uma planilha Excel salva como CSV, ou exportada de sistemas como Superlógica, Cond21, SAMI.

Colunas reconhecidas:
nome · unidade · bloco · email · telefone · tipo (proprietario/inquilino)

⚠️ A primeira linha do arquivo deve ser o cabeçalho com os nomes das colunas.
🏢 Importar Condomínios (CSV)

Importe sua lista de condomínios de uma planilha.

Colunas reconhecidas:
nome · endereco · unidades · blocos · cnpj

⚠️ A primeira linha deve ser o cabeçalho. Condomínios com mesmo nome serão ignorados (sem duplicatas).
📥 Importar Leituras (CSV)

Importe leituras exportadas de sistemas como Superlógica, Cond21, SAMI ou qualquer planilha Excel salva como CSV.

Formato esperado das colunas:
unidade, leitura_agua, leitura_gas, data
